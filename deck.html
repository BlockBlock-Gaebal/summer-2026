근데 AI를 운영자가 돌리면?

GymPact와 같아진다. 그래서 판정 근거를 Walrus에 공개로 남긴다 — blobId를 알면 누구나 재생 가능.

돈과 정산은 운영자를 믿지 않는다.
판정은 재생 가능하게 만들었고, 판정의 탈중앙화가 다음 단계다.

R(k) = α·(k/D) + (1−α)·(k/D)²
  • k일 버티고 탈락하면 예치금의 R(k)를 환급

  • 몰수분은 한 번에 나눠주지 않고 남은 날에 걸쳐 스트리밍 재분배

한계와 확장

아직 안 된 것, 다음에 할 것

데모에서는 오라클이 참가자 A와 동일 주소다
→ 컨트랙트는 오라클을 별도 주소로 받는다. 실서비스에서는 오라클 키를 참가자와 분리
Walrus blob은 공개 — 제출 원문이 노출된다
→ Seal로 원문은 가리고 판정 근거만 공개하는 분리
텍스트 증빙은 위조가 쉽다
→ 컨트랙트는 "누가 탈락했는가"만 받는다. 증빙 타입은 교체 가능한 부품
오라클 권한 제한·회수를 온체인으로 강제하지 못한다
→ submit_results가 ctx.sender()를 검사하는 구조. 강제하려면 재배포
참가자 상태가 shared object 하나에 있다
→ 프로토 목표는 정산 수식 검증이었다. 참가자별 객체 분리로 병렬성 확보
지갑 UI가 없다
→ 참가·예치·판정·정산은 전부 실제 온체인 트랜잭션. UI는 스코프에서 제외
LLM 판정은 실행마다 흔들릴 수 있다
→ dry-run 명단과 다르면 제출하지 않는다 (--expect-fail). 되돌릴 수 없는 호출 앞의 안전장치
